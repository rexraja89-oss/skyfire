# Skyfire asset inventory and baseline (step A)

Read-only snapshot of the game at **v5.22** (`1f0e855`). Data: `inventory.json` (same folder). No game files changed.

## Size
- APK: **22.3 MB** (release build-44)
- Web download at first start (page, scripts, three.js, menu music, first textures): **7.5 MB**
- Everything after visiting all 10 stages: **16.3 MB**; `art/` holds 15.7 MB in 62 files

## Notes for the next steps
- Biggest visual gaps: textured 3D vehicles (jets, tanks, ships), explosion/fire VFX, lighting (no HDRI/bloom).
- Budget headroom: the heaviest stage draws ~590k triangles and ~83 calls; scene textures stay under ~25 MB. Room exists for KTX2-compressed hero assets, but phone FPS must be checked on the S22 first (Balance lab FPS counter).
- Loader files for glTF/KTX2/meshopt (three r128 + meshoptimizer 1.3, MIT) are prepared but parked outside the repo until assets are approved.
