# Skyfire Squadron

An original vertical arcade shooter by Rex, built as a single HTML file that runs in a phone browser.

- 6 stages, each ending in a boss fight
- Gears currency, magnet pickup, 3 medals per stage
- Hangar with 6 upgrades (8 levels each)
- Rex's Workshop: unlimited gears, max upgrades, unlock all stages, invincible mode

## Play

Open `index.html` in a browser, or use the GitHub Pages link once Pages is enabled.

Controls: drag anywhere to fly (guns fire automatically), tap BOMB to clear bullets. On desktop: arrow keys / WASD to move, Space for bomb, Esc to pause.

Progress saves in the browser's local storage on each device.
